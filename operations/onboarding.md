# Подключение сотрудника QSRE

1. Клонируйте репозиторий с `--recurse-submodules`.
2. Прочитайте `README.md`, `AGENTS.md` и оба QSRE contracts в control submodule.
3. Выполните doctor и repository validation.
4. Работайте через отдельную ветку и Pull Request.
5. Проверяйте внешние артефакты по полным SHA, не копируя их сюда.
6. Сохраняйте независимость: автор реализации не подменяет QSRE review.
