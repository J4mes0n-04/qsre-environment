# Безопасность

- Не добавляйте credentials, `.env`, production dumps и чувствительные evidence в Git.
- Используйте immutable references и полный commit SHA.
- Не исполняйте непроверенный код из входного handoff.
- Для R3 обязательны threat analysis, независимое одобрение и проверенный rollback.
- Security findings передавайте через согласованный приватный канал и связывайте с review ID без раскрытия чувствительных деталей.
