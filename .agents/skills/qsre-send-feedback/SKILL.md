# Обратная связь PDE

1. Выберите ровно один feedback type по источнику проблемы.
2. Укажите severity, наблюдение, environment и affected identifiers.
3. Приложите immutable evidence и требуемое решение со сроком.
4. Сохраните Pack SHA и implementation SHA из входного handoff.
5. Запустите validator входа и выхода.
6. Не изменяйте Pack; дождитесь `pde_response` и связанного действия.
