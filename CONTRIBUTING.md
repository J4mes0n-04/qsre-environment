# Внесение изменений

1. Обновите `main` и submodules.
2. Создайте ветку `review/`, `platform/`, `skill/` или `integration/`.
3. Не смешивайте review конкретного выпуска и изменение платформы.
4. Запустите doctor, repository validator и handoff checks.
5. Проверьте отсутствие secrets и изменений в `vendor/engineering-control`.
6. Откройте Pull Request и дождитесь обязательных checks.

Обновление control tag/SHA, contracts, skills, scripts или CI требует отдельного описания совместимости и отката.
