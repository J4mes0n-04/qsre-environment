# Каталог файлов QSRE

- `README.md` — назначение, границы и запуск среды.
- `AGENTS.md` — обязательные инструкции агентов QSRE.
- `CONTRIBUTING.md` — порядок изменений и Pull Request.
- `SECURITY.md` — базовые требования безопасности.
- `CHANGELOG.md` — история версий QSRE Environment.
- `config/control-plane.yaml` — pin `engineering-control` и contracts.
- `config/features.yaml` — состояние инструментов.
- `architecture/` — системный контекст и структура.
- `operations/` — onboarding и review runbook.
- `templates/` — ACK, review plan и release decision.
- `scripts/doctor.ps1` — prerequisites.
- `scripts/validate-repository.ps1` — целостность QSRE и control pin.
- `scripts/validate-handoffs.ps1` — contracts ASE → QSRE и QSRE → PDE.
- `.agents/skills/` — четыре начальных QSRE skills.
- `.cursor/rules/` — ограничения независимой проверки.
- `.codex/config.toml` — подготовленный и выключенный OpenSpace local MCP.
- `.github/` — CODEOWNERS, PR template и CI.
- `workspaces/projects/` — review records.
- `vendor/engineering-control/` — read-only submodule общей основы.
